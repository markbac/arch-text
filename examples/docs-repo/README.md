# Sample docs repository

A minimal docs repository that keeps its architecture diagrams as `.archt` text and lets CI draw them. Copy what you need from here:

- [`docs/architecture/platform.archt`](docs/architecture/platform.archt): the diagram's source.
- [`docs/architecture/platform.svg`](docs/architecture/platform.svg): the drawing, generated by the arch-text Docker image and committed beside its source, so Markdown can show it.
- [`.github/workflows/diagrams.yml`](.github/workflows/diagrams.yml): regenerates and commits the SVGs on pushes to `main`, and fails pull requests whose SVGs are out of date.

arch-text's own CI renders this folder with the image it has just built and checks that nothing changes, so the committed SVG always matches what the action would make. [docs/docs-repo.md](../../docs/docs-repo.md) explains the set-up.
